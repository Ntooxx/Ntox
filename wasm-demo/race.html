What am I looking at?
Both sides run the same algorithm, same input, same machine. WASM is Rust compiled to WebAssembly (~11 KB inlined in this file); JS is plain JavaScript. Bars are scaled to the slower side, so shorter = faster. Results are median of 3 runs to filter out GC pauses and thermal noise. Why does JS sometimes win? Modern JS engines (V8/JSC) JIT-compile hot functions into machine code too, and JS runs without WASM's bounds checks. WASM wins where memory-heavy or float-heavy work dominates — that's benchmarks 1–3.
