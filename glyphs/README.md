# NTOX glyph studies

A black-and-white design collection with a standalone gallery and a desktop integration. The gallery uses no provider, API, credentials, or network connection.

## Open the preview

Open **index.html** directly in a modern browser. No server or installation is needed.

- Select any of the 21 cards to inspect its animated artwork and navigation icon.
- Use the previous/next controls to compare the forms.
- Pause motion to study the geometry, or choose the more energetic Active study.
- Try **Intro → Agents** and **Intro → Chat** to inspect the particle transition proposals.
- Download each SVG from the selected glyph panel.
- System reduced-motion preferences produce a still image and immediate transitions.

Animations are design studies, not real runtime activity. The transition preview morphs between glyphs inside the studio; it does not navigate to a working dashboard or chat.

## Files

- `artwork/`: 21 individual 320-unit SVG illustrations. Each has an accessible title and a transparent outer background; planetary silhouettes contain black fills.
- `icons/`: 21 individual 24-unit SVG navigation glyphs, drawn for small sizes.
- `manifest.json`: names, groups, descriptions, and paths for future integration.
- `catalog.js`: glyph metadata and navigation paths.
- `geometry.js`: deterministic geometry shared by static SVG export and animated preview.
- `preview.js`, `preview.css`, `index.html`: independent gallery.
- `generate.mjs`: rebuilds all SVG assets and the manifest.
- `geometry.test.mjs`: built-in Node tests for completeness, finite geometry, reproducibility, and monochrome exports.
- `review.cjs`: browser interaction and responsive checks using the repository's Playwright dependency and installed Microsoft Edge.
- `previews/`: review screenshots and results generated by the browser checks.

## Motion and rendering

The preview uses projected 3D geometry on one Canvas 2D surface, with particle reconstruction, orbital signal travel, and slow changes in viewpoint. It uses no remote libraries or fonts. Gallery cards use static SVGs so 21 animation loops do not run at once.

The transition study lasts approximately 900 ms. Pausing, reduced motion, a hidden browser tab, and scrolling the studio offscreen stop the animation loop. Canvas resolution is capped at twice the CSS size. If a 2D context is unavailable, the selected SVG is shown instead.

These are geometric interpretations of the supplied visual references. The studio remains a design review artifact. The desktop now uses this collection for section artwork, navigation and identity icons, and transitions between the intro, dashboard, and chat. Decorative motion does not represent runtime activity.

## Desktop integration

`node glyphs/sync-desktop.mjs` exports the catalog, geometry, and 21 static fallbacks into `desktop/glyphs/`. Edit the originals here, then sync; avoid editing generated copies.

The production renderer is `desktop/glyph-motion.js`, with presentation in `desktop/glyph-motion.css`. It uses one shared animation scheduler, pauses when hidden or offscreen, respects reduced motion, and provides a persistent pause control. The planetary photograph appears only on Overview.

See `docs/GLYPH_INTEGRATION.md` for the section mapping and implementation notes.

## Rebuild and review

From the repository root:

```powershell
node glyphs/generate.mjs
node --test glyphs/geometry.test.mjs
node glyphs/review.cjs
```
